# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-19

### Added
- **20-Year Interactive Timeline**: Chronological device navigation spanning 2006–2026 across 26 devices (13 phones, 8 laptops, 5 desktop PC builds).
- **Multi-Category Filtering**: Instant switching between All, Phones, Laptops, and Desktops.
- **Device Detail Dialogs**: Accessible modals with Overview, Hardware Specifications, and Benchmark metrics tabs.
- **Dual Navigation**: Smooth mouse dragging, touch swipe gestures, and full keyboard arrow navigation.
- **Accessibility & Motion**: Semantic dialogs, focus traps, and full `prefers-reduced-motion` support.
- **Zero-Dependency Engine**: Pure vanilla JavaScript ES modules with Node.js test runner suite.
- **Live Deployment**: Hosted on Cloudflare Pages at [devices-over-time.pages.dev](https://devices-over-time.pages.dev).
